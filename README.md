# Clearly Email Marketing Dashboard — Live Demo

This repo hosts only the **live demo** of the Clearly Email Marketing Dashboard
(sample data, locked: edits reset on refresh, no Backup/Restore).

The full product — with autosave, Backup & Restore, and a clean start for your
own data — is available on Etsy.

`index.html` is a generated build; it is updated by the seller's private build
pipeline. Everything runs client-side: no server, no tracking, works offline.
